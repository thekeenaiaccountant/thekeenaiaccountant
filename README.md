# The Keen AI Accountant

I am an Australian Chartered Accountant exploring how AI and automation can support better finance work.

This is a learning portfolio. I tinker, test ideas, document what worked, note what did not, and stay open about what I still need to understand. The work shared here is experimental, not a claim to have every answer.

## What I am exploring

- Practical finance automation using fictional scenarios
- Controls, reconciliations, approvals, and exception handling
- Responsible uses of AI in accounting and vCFO work
- Clear documentation of lessons, limitations, and failures

## Public data boundary

Everything published here is created from scratch for learning or demonstration.

I do not publish client names, transactions, amounts, dates, account codes, documents, screenshots, identifiable workflows, credentials, API keys, or connections to live systems. Real client work remains in approved private systems.

## How I work

1. Start with a clearly defined finance question.
2. Build and test with fictional data.
3. Add privacy, reconciliation, and approval controls.
4. Document gaps and what I learned.
5. Require human review before any real-world decision or action.

## A work in progress

This portfolio will grow as I learn. Some experiments will work, some will not, and both belong in an honest learning record.

> Learning and demonstration only. Nothing in this portfolio is accounting, tax, legal, or financial advice.
